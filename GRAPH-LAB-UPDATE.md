# ConceptLab Graph Lab expansion

The Graph Lab catalog now includes 191 interactive graph activities grouped into 25 HSC chapter sections:

- Physics 1st Paper: 76 graphs across the existing 10 chapters (preserved).
- Chemistry 1st Paper: 55 graphs across the 5 requested chapters.
- Higher Mathematics 1st Paper: 60 graphs across the 10 requested chapters.

## Graph Lab interface

The catalog begins with four subject filters: All Graphs, Physics 1st Paper, Chemistry 1st Paper, and Higher Mathematics 1st Paper. Searching works within the currently selected subject.

Each graph has an editable parameter number field as well as a slider, editable x/y axis limits, sample-count control, animation, CSV and PNG export, and a custom-data editor. To plot own data, enter one `x,y` pair per line and press **ডেটা প্রয়োগ**.

## Scientific note

Several chemistry graphs are clearly presented as illustrative trend/model graphs because real data can vary with the selected element, compound, solution, temperature, pressure, and experimental conditions. Use measured values when a lab report requires empirical data.

## Build

The static build was regenerated with `npm run build`; the source files and `dist/` copy are included.
