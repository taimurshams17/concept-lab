# Qualitative Chemistry — content and source note

- Qualitative Chemistry currently contains 31 concept entries (`qc-01`–`qc-31`).
- Each concept has a dedicated Stage 3 simulation key; the chapter no longer routes every concept to the same Bohr simulation.
- The eight added fine-grained entries include atomic/mass number, isotope/isobar/isotone comparison, shell capacity, subshell/orbital counts, Aufbau and Hund rules, electron-configuration exceptions, and valence electrons.
- Each concept has a 10-question practice set (310 questions across 31 entries).

**Important source limitation:** the supplied 177-page PDF is scanned, and its printed headings and original MCQs have not yet been verified page-by-page in this build. Quiz items in this package are concept-check practice questions, not claimed to be verbatim PDF questions. Do not label them as original PDF MCQs until a page-by-page source audit is completed.
